HALAXY CLINIC STATIC WEBSITE DEMO

OPEN LOCALLY
1. Extract this ZIP file.
2. Double-click index.html. No server or installation is required.

DEMO LOGIN
Patient: patient@halaxy.demo
Clinic staff: doctor@halaxy.demo

FEATURES
- Responsive clinic landing page
- Demo patient and staff login
- Portal overview and appointment list
- Appointment request form
- Requests saved in the current browser using localStorage

PUBLISH ON NETLIFY
1. Upload the contents of this folder to the root of your GitHub repository.
2. In Netlify, import that repository.
3. Leave the build command blank.
4. Set publish directory to . (dot), then deploy.

IMPORTANT
This is a static demonstration only. It has no secure server-side authentication,
cloud database, cross-device syncing, email notifications, or real appointment
booking. Data is stored only in the browser that entered it and may be cleared.
Do not enter real patient or health information. A real clinic system needs
secure backend services, access controls, backups and applicable privacy-law
compliance (including POPIA where applicable).
